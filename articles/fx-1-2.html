환율을 이해하는 출발점
: 국가, 화폐, 교역
환율은 그냥 생겨나지 않아요. 딱 세 가지가 맞아 떨어질 때만 존재합니다. 국가, 화폐, 그리고 교역.
CONCEPT
환율이 존재하려면 이 세 가지가 필요하다
환율을 이해하려면 먼저 이 세 가지를 알아야 해요. 하나라도 빠지면 환율 자체가 성립하지 않거든요.
1
국가 (Nation)
서로 다른 국가가 최소 두 개 이상 있어야 해요. 국가가 하나뿐인 세계에선 환율이 필요 없죠. 같은 나라 안에서는 서울에서 받은 돈을 부산에서 그대로 쓸 수 있잖아요.
2
화폐 (Currency)
두 나라가 서로 다른 화폐를 써야 해요. 같은 화폐를 쓰면 환율이 필요 없습니다.

예시 엘살바도르는 미국 달러를 자국 통화로 사용해요. 그래서 엘살바도르-미국 사이엔 환율이 없어요. 유로존 20개국도 마찬가지예요. 독일과 프랑스는 국가는 다르지만 유로화를 같이 쓰기 때문에 서로 간 환율이 없습니다.
3
교역 (Trade)
두 나라가 실제로 거래를 해야 해요. 거래가 없으면 화폐를 바꿀 일이 없으니까요.

예시 조선시대 우리나라와 아프리카 가나는 국가도 다르고 각자의 화폐도 있었어요. 하지만 양국 간 교류가 전혀 없었기 때문에 환율을 따질 필요가 없었죠.
환율의 성립 조건 한 줄 정리

✅ 다른 나라 + ✅ 다른 화폐 + ✅ 서로 거래 → 비로소 환율이 필요해진다
DEEP DIVE
세계 환율은 몇 개나 될까?
세계에 나라가 150개라면 이론적으로 환율의 수는 어떻게 될까요?
계산식: (150 × 149) ÷ 2 = 11,175개

나라 쌍의 수만큼 환율이 생겨요. 150개 나라가 둘씩 짝을 지으면 이 숫자가 나옵니다.
그렇다고 실제로 1만 개가 넘는 환율을 일일이 따지진 않아요.

현실에서는 달러가 중간 다리 역할을 합니다. 우리나라 외환시장에서 직접 거래되는 통화는 단 두 가지예요.
원화 ↔ 달러
한국 외환시장에서 직접 거래
원화 ↔ 위안화
한국 외환시장에서 직접 거래
나머지 통화들은요? 달러를 거쳐서 계산합니다. 이걸 재정환율(Cross Rate)이라고 해요.
CONCEPT
재정환율: 달러가 중간 통역사 역할을 한다
직접 만나서 대화하기 어려운 두 사람이 통역사를 끼고 소통하는 것처럼,
원화와 유로화도 달러를 통역사로 삼아 환율을 계산해요.
원화 ↔ 유로화 환율 계산 예시
시장환율
한국 외환시장 (원↔달러) 1달러 = 1,000원
뉴욕 외환시장 (달러↔유로) 1유로 = 1.2달러
계산된 재정환율 (원↔유로) 1유로 = 1,200원 (1,000 × 1.2)
원화
→ 1,000원/달러 →
달러 (통역사)
→ 1.2달러/유로 →
유로화
→ 결과 →
1유로 = 1,200원
원화 ↔ 엔화 환율도 마찬가지
시장환율
한국 (원↔달러) 1달러 = 1,000원
도쿄 (달러↔엔) 1달러 = 100엔
재정환율 (원↔엔) 100엔 = 1,000원
TIPS
나라마다 환율 표시 방식이 다르다
환율을 적는 방식도 나라마다 달라서 처음엔 헷갈릴 수 있어요.
표시 방식해당 국가예시
1달러당 자국 화폐 한국, 일본, 중국 1달러 = 1,300원 / 1달러 = 150엔
1자국 화폐당 달러 유럽, 영국 1유로 = 1.1달러 / 1파운드 = 1.3달러
쉽게 기억하는 법 : 한국·일본·중국은 "달러 1개가 내 돈 몇 개야?"로 표시하고, 유럽·영국은 "내 돈 1개가 달러 몇 개야?"로 표시해요. 역사적 관행에서 굳어진 거라 딱히 이유는 없어요.
SUMMARY
오늘의 핵심 정리
환율의 3대 조건

1. 국가 — 서로 다른 나라가 2개 이상 있어야 한다
2. 화폐 — 각 나라가 서로 다른 돈을 써야 한다
3. 교역 — 두 나라가 실제로 거래를 해야 한다

재정환율 — 직접 거래 시장이 없는 통화들은 달러를 거쳐 계산한다

👉 달러는 환율 세계의 공통 언어 역할을 한다
